Tray closure icons

Isometric tray + closure with an orange motion arrow. Three SVGs, 64×66 viewBox, scalable. Teal = closure (#176b8a), orange = motion (#d1451f). The arrow halo is #f4f1ea — recolor it to match the surface you place the icon on.

Using them

Drop the .svg files into your assets and reference with <img src="lid.svg">, or paste the SVG markup inline to control colors via CSS. To recolor: closure fills/strokes use the teal above, the arrow uses the orange. Set a fixed width (e.g. width:24px) — the viewBox scales cleanly.
